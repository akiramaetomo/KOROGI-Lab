# model

`documents.ts` validates and normalizes plain timbre/session data before application.
Timbres contain source settings, FX1, BURST articulation, Auto timing, per-source detune, and Auto/User sequence data; sessions embed timbres and add instance levels, mute, Near/Far sends, shared buses and Master state.
Generic sessions have unique channel IDs; `parseLabSession` accepts the Lab's eight slots (IDs 1–8) or pads a valid four-slot Session with empty slots 5–8 before application.
`patch.ts` provides shared structural/type validation helpers. New files use timbre-v16/session-v17. The editor layout stores left-to-right columns of one or two card IDs; Large cards occupy a column alone. Timbre v12-v14 flat layouts migrate to one card per column. FEnv owns independent ADSR, curves, mode, Release timing, signed Amount and enable state. Older timbres get FEnv OFF and neutral Amount; v12 editor layouts are retained. New FEnv settings are required and invalid Rate/Exponential pairs are rejected. PEnv mode is independent of AEnv mode and required in new files; older files inherit the old AEnv mode. Auto saves Ton and a common repeat period; old One-shot without BURST inherits its old One-shot period, otherwise Ton plus Toff. PEnv saves four percentage points, three times, scale, and Release timing; AEnv saves Release timing. Old PEnv Amount/Time are discarded and replaced with neutral ADSR values, with a visible import notice. Old AEnv Release uses Time. Invalid Rate/Exponential pairs in new files are rejected. Independent Gate User 1–3 and Pitch User 1–3 arrays have stable IDs, recordings, and mute flags. Each Pitch User owns scale mode, steps, portamento, pitch scale, signed Filter Amount and a saved Wide toggle (older formats migrate to zero); the Timbre owns Record/Play Speed, both selected IDs, and Auto/recorded Gate mode. Legacy User 1/2 lanes map to the corresponding new IDs, legacy Auto Pitch maps to Pitch User 3, and the old playback source selects common speeds and active IDs. Legacy 0 and intermediate Pitch Scale values remain unchanged. Earlier migrations for BURST, OSC phase, FILTER2, Pan, and internal OFF remain supported. Link and running positions are transient. Old v1 and legacy harness v4 are rejected before audio application.
`triggerRecording.ts` validates a bounded, ordered external phrase-Gate interval list and clips it to a non-destructive selection. `sequencePitch.ts` validates normalized Pitch point lists, sequence settings, quantization, and loss-bounded curve simplification. BURST-generated pulses are not recorded. Sessions embed the sequence data with each timbre. No live AudioNode state, active Gates, playback positions or effect tails are serialized.
