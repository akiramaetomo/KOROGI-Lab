# ui

The current UI is a fixed-viewport four-timbre Lab PoC.
`MixerPanel` keeps four instance strips and their Gate queues; each strip has Load, Save, Init and Clear with Save disabled while empty. FILES handles Session files only. `main.ts` binds the existing detail editor to one selected source and common controls to the engine.
`ManualGateController` retains gesture-to-source ownership across selection/replacement, combines simultaneous Gate owners, waits for the first audio resume only while a gesture is held, and handles keys 1–4, pointer cancellation and focus loss.
`TriggerRecorder` handles the dedicated large Gate button, AudioContext-clock recording and timeline selection. It commits a new take only on recording end and locks its selected timbre while recording. `SequenceTransport` owns per-slot Auto/User playback, a common Play All start time and pending start cancellation; other slots can play during recording.
The slot list, combined TIMBRE/COMMON SPACE signal map and detail editor can scroll internally; the two diagram cards do not scroll independently. The page does not scroll. Each occupied slot edits its own Timbre Name.
It is still a research/verification UI rather than the final KOROGI-Dream interface.
TIMBRE FX1, COMMON SPACE FX2/FX3/Gain and COMMON SPACE OUTPUT use separate editor pages. Bus selection never changes sends or source selection. At 1024px the three common FX/Gain cards stay side by side with a 1:1:0.7 width ratio; narrower widths stack them.
SignalMap renders an interactive selected TIMBRE frame and COMMON SPACE with four input terminals, stacked Near/Far chains and horizontal Output Balance→Master→Limiter. Timbre nodes use a 96×30px border-box: enabled processes use the editor selection palette with a 1px border, disabled processes retain the muted 1px treatment, and editing adds an independent 2px cyan outer ring. The equal-size 24×22px FX1 `MON` and ON/OFF controls stay inside the node without changing editor focus. MON OFF draws a minimum 24px FX1→`COMMON SPACE` line plus Output Balance→Master; MON ON replaces both with a right-and-down FX1→Master path outside SEQUENCE. FILTER2 cutoff routing exits the FILTER2 right edge, runs horizontally, then turns upward once into the FILTER1 bottom edge without crossing MOD. The 42px Σ nodes center four entry arrows; the first Near and fourth Far paths enter horizontally. Vertical send bends sit 8px farther toward the inputs. PEnv uses a short dashed control arrow with a destination label. HTML nodes open matching editors; all blocks editable in the active panel, including Bus Gain, Output Balance and Master, are illuminated. SVG draws audio/control wires in content coordinates. ResizeObserver recalculates ports. Bus Gain, Output Balance and Master are readouts in the graph and horizontal controls in their editors. FILES is in the header and SEQUENCE at the TIMBRE bottom right. A draggable divider starts with a 50/50 graph/editor share; dragging suppresses text selection.

`NumericSliderControl.ts` retains text entry, caret-digit arrows, wheel and Shift-wheel. Bounds, default, scale, Fine mode and orientation come from [`parameterRanges.ts`](../config/parameterRanges.ts). OSC1/2 Fine independently selects an anchored ±10/30/50% Hz window, defaulting to ±50%. Double click/tap resets Fine to its anchor and center; Coarse retains its default reset. Fine anchors are UI-only and are not persisted. The control dispatches the existing numeric change event; programmatic value changes and disabled state synchronize both surfaces. `sliderTapReset.ts` recognizes repeated touch double taps separately from drags. Editable fields retain text selection while other app labels suppress long-press selection. [`parameterSafety.ts`](../config/parameterSafety.ts) validates author edits before audio graph creation and reports the file, field and reason in the header.
