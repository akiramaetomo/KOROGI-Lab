# KOROGI-Lab — 公開仕様

## 音源と発音

- 8つのTimbreは独立したモノフォニック音源です。各Timbreは2 OSC、PEnv、MOD、FILTER1／2、AEnv、BURST、FX1を持ちます。
- OSC1／2はsine、sawtooth、triangle、square、white noiseを選択できます。周期OSCはTimbre共通のSYNC／FREEを持ちます。
- Manualは押下中Gate、AutoはTonと反復周期、User 1／2は記録したGate列を使用します。Play Allは各枠の選択中再生元を共通時刻から開始します。
- AEnvはGateまたはOne-shotです。BURSTはOne-shotを1発として1〜8発の群を構成し、外側のManual／Auto／Userをフレーズ窓として扱います。

## Mixと空間処理

- FX1前は固定−18 dBです。歪量はFX1 Drive、完成したTimbreの音量はFX1後Levelで調整します。
- FX1後にL/R Panと等電力Near／Far送信を適用します。Near／FarはそれぞれFX2、FX3、Bus Gainを持ちます。
- Output BalanceでNear／Farを等電力合成し、Master Gain／MuteとSafety Limiterを通して出力します。
- FX1のMONは選択TimbreのFX1直後をMasterへ一時的に直結します。Sessionには保存しません。

## 保存と読込

- 新規Timbreは`timbre-v7`、新規Sessionは`session-v8`で保存します。
- 対応する旧形式は、位相、BURST、User Pattern、Panなど不足項目を規定値で補って読込みます。不正・未知・重複した構造はライブ音声グラフへ適用する前に拒否します。
- Sessionは8枠、User Pattern、共通空間を含みます。個別TimbreのLoadは共通空間を変更しません。
- DemoとSession Loadは再生・録音を停止して状態を置換しますが、自動発音しません。

## 操作と表示

- 数値範囲、既定値、線形／対数、Coarse／Fine方式は`src/config/parameterRanges.ts`を正本とします。
- 固定viewport内でTIMBRES、信号図、エディットを意味のある領域ごとにスクロールします。
- iPadでは編集可能な入力以外の長押し文字選択を抑止します。タッチによるAudioContext再開はpointerupでも再試行し、解放済みGateを遅延発音させません。
