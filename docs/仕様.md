# KOROGI-Lab — 公開仕様

## 音源と発音

- 8つのTimbreは独立したモノフォニック音源です。各Timbreは2 OSC、PEnv、MOD、FILTER1／2、AEnv、AEnv2、BURST、FX1を持ちます。
- OSC1／2はsine、sawtooth、triangle、square、white noise、LFSR noiseを選択できます。周期OSCはTimbre共通のSYNC／FREEを持ちます。
- 各OSCはSingle｜Multiを選べます。Multiは同じ波形を1～16基加算します（`y(t) = Σ A_n·w(2π f_n t)`）。各成分はBase Frequencyに対する比で保存し、PEnv、Detune、Sequence Pitch、FMは全成分へ同じ比で作用します。定義はSpread（Count、±cent、各振幅1/N）またはTable（行ごとのHzと振幅、貼付・コピー可）です。成分数が変わる操作は10 msのfadeで組み替えます。White NoiseはMultiの設定を保持したままSingleで鳴ります。
- **LFSR Noise**: 31段のLFSR（`b[t] = b[t−31] ⊕ b[t−13]`）の連続するBits個（1～16）のビットを整数にし、−1～＋1へ線形に写します。Noise Clock（100 Hz～sampleRate）ごとに値を更新し、間は保持します（ZOH）。Clock・Bitsごとの10秒のテーブルを全Timbreで共有し、Gate Onごとにテーブル上の乱数位置から読み始めます。Clock・Bitsの変更は次のGate Onから反映します。音程を持たず、Base Frequency、Detune、PEnv、Sequence Pitch、FMは効きません。
- **FILTER2**: 直列2段（Stage1→Stage2）です。Stage1のTypeはLPF／BPF／HPF／LShelf／HShelf／Peak、Stage2はこれにOff（既定、素通し）を加えます。Orderは1st／2nd／4thで、BPF・Peakは2nd・4thだけ、1stはLPF／HPF／Shelfだけです。Shelf・PeakはGain（−24～＋24 dB）を持ち、4thは各段にGainの半分を掛けます。1次はcutoffの変調を受けません。FEnvはFEnv Depthを経て、FEnv Target（Stage1／Stage2／Both）で選んだ段に掛かります。
- **Q**: FILTER1／2の全Typeで線形のQ（0.1～30、既定0.707）を使います。LPF／HPFでは0.707がButterworth（山なし）で、2nd・4thでは共振の山をdBで示します。BPF・Peakでは幅を決め、Shelfでは使いません。
- OSC2→FILTER2系（2系）の行き先は、MOD／F1 CUTOFF／AEnv IN／AEnv OUTの排他な4択です。MOD以外ではMODの設定を保持したままN/Aにします。
  - **AEnv IN**: 2系をFilter1の出力と加算し、AEnv1へ入れます。AEnv2は掛かりません。
  - **AEnv OUT**: 2系をAEnv2に通し、AEnv1の後で加算します。AEnv2はADSR・Curve・Release方式とGate／One-shotを独立に持ち、BURSTの各打でも起動します（Gateならその打の終端でRelease）。AEnv OUT以外ではN/Aです。
  - **Balance**: AEnv IN／OUTで、−100（1系のみ）～0（両系とも0 dB）～＋100（2系のみ）。中央では2つの音が加算されます。
  - **FEnv Depth**: FEnvは1系と共通で、Filter2へはFEnv Amountの−100～＋100 %で掛かります（既定0 %、全経路で有効）。
- Manualは押下中Gate、AutoはTonと反復周期、Pattern 1～8は記録したGate／Pitch列を使用します。GateとPitchは番号・長さを独立に選べます。
- AEnvはGateまたはOne-shotです。BURSTはOne-shotを1発として1〜8発の群を構成し、外側のManual／Auto／Patternをフレーズ窓として扱います。

## 時間方式（Seconds｜Bars）

- ヘッダーの`Seconds | Bars`はアプリ全体で1つの時間方式です。新しいSessionはBars（BPM 120、Frame 4小節、各Pattern 1小節）で始まります。時間方式を持たない旧Session（`session-v17`以前）はSecondsで読み込みます。
- 記録データは秒だけです。方式、BPM、小節数、Play/Rec Speedは、その秒の読み方と鳴らし方の設定です。録音中は方式を切り替えられず、再生中に切り替えるとLoopとChainを停止します。
- **Seconds**は、範囲指定だけを行うサンプラー的な方式です。速さはPlay/Rec Speedで決まり、Gate Quantize、Match Fit、クリック、Gridは使いません。
- **Bars**は、ルーパー的な方式です。各Timbreは基準Pattern（記録GateならGate Pattern、AutoまたはGateが無ければPitch Pattern）のPattern長×240÷BPM秒へ、GateとPitchの選択区間を伸縮してループします。倍率は`選択区間長÷ループ長`で、Pattern付近に`×1.08`のように示します。
  - Pattern長はTimbre×Pattern番号ごとの値で、`1/16`・`1/8`・`1/4`・`1/2`・`1`〜`32`小節から選びます。
  - 再生中の全Timbreが1小節の格子を共有し、途中からの開始とPatternの切替は次の小節頭で行います。BPM（30～480）の変更は小節内の位置を保って追従します。
  - 録音も同じループ長で周回し、入力は記録秒へ戻して保存します。他のTimbreが鳴っていれば次の小節頭から録り始め、伴奏は再始動しません。録音中はGrid線とクリック（4/4）を使えます。

## LoopとChain

- **Loop**（SONG欄の`▶ Loop`）は、各Timbreで選択中のGate／Pitch Patternを、開始時刻だけそろえて独立にループさせます。Barsでは各TimbreがPattern長でループし、番号の異なるPatternはループ長の最小公倍数ごとに頭がそろいます。Secondsで周期が整数倍の関係にないときは`⚠ Loops drift`を表示します。
- **Chain**（`▶ Chain`）は、全Timbreで同じ番号のPatternを、共通の時計でPattern 1→8の順に鳴らし、全体を繰り返します。Autoは含めません。録音中は開始できません。
  - Barsの各区間は`Frame長×240÷BPM`秒です。Frame長はSession共通の1〜32小節です。各PatternはPattern長のままループして区間の終わりで切れ、Frameより長いPatternは縮めて鳴らします。
  - Secondsの区間長は`最長のGate選択区間÷Play/Rec Speed÷Song Speed`です。
- LoopとChainは、片方を始めると他方が止まります。
- **再生中の変更**: Pitch設定（Scale、curve、Steps、Portamento、Filter Amount、Wide）はすぐ効きます。記録、選択区間、Quantize、Pattern長、Frame長の変更は、Chainでは次の区間の頭から、Loopではループの境目（BarsのPattern長と切替は次の小節頭）から効きます。

## SONG欄の格子

- 行はTimbreの入った枠、列はFrame 1〜8（Frame nには各TimbreのPattern nが入ります）です。セルの文字は記録の有無（`G`／`P`／`GP`／`–`）を示し、緑はChainで鳴らす、暗い表示は休符です。全TimbreがOFFの番号は区間ごと飛ばします。
- セルの1回目のタップで、そのTimbreを選び、SEQUENCEのGateとPitchをそのPatternにします。青枠のセルをもう一度タップするとChainでのON／OFFを切り替えます。行頭の名前は、Timbreだけを選びます。
- 各行の上辺の帯はSEQUENCEのGate Pattern、下辺の帯はPitch Patternを示し、そのTimbreが鳴っている間は赤、止まっている間は灰色です。Chainで鳴っている列は列見出しを赤にします。
- ヘッダーの`SEQUENCE`はSEQUENCE画面を開きます（Map・TIMBRESを畳んでいても開きます）。

## SEQUENCEの入力と編集

- Separate未選択ではスライダがGate＋Pitchを兼ね、選択中は独立GateボタンとPitch専用スライダになります。Record対象レーンを優先し、Playでは手動保持中のレーンだけをコントローラへ切り替え、解放時に進行中の記録・Auto・Chainの現在位置へ戻します。Separateは一時状態で保存しません。
- Gate Hold／Pitch Holdは、離した後もGate ON／コントローラPitchを保持します。保持中の再押下はレガートで再トリガせず、Hold OFFで解除します。録音中は保持の間もGateとPitchのPunchが続きます。どちらも保存しません。
- 録音中も、Pitch設定とSeparate（GateとPitchの入力を保持していない間）は変更できます。Play/Rec Speed、選択区間、Pattern番号、Bars、BPMは録音中は変更できません。
- レーンのMuteは出力だけを止め、Loop・ChainでのLoopの時計、カーソル、位相は進め続けます。ChainのOFFセルとは異なり、全ての再生で消音し、区間を消しません。
- Pitch Scaleは−2400～＋2400 centの対称な11段です。負のScaleはPitchの動きを反転します。RecordのWriteは既定でOverdubです。
- Gate Quantize（Barsのみ）は、Pattern長の4/4格子へ、独立した編集範囲内のGateを量子化します。1/4・1/8・1/16・1/32（Pattern長で割り切れる格子のみ）、ONのみ・ON/OFF、Gap 1～20 ms、直近1操作のUndo／Redoを持ちます。
- Copy Patternは同じTimbre内でPatternを複製し、Pattern長とChainのON／OFFも引き継ぎます。記録のあるコピー先は上書きを確認します。

## Mixと空間処理

- FX1前は固定−18 dBです。歪量はFX1 Drive、完成したTimbreの音量はFX1後Levelで調整します。
- FX1後にL/R Panと等電力Near／Far送信を適用します。Near／FarはそれぞれFX2、FX3、Bus Gainを持ちます。
- Output BalanceでNear／Farを等電力合成し、Master Gain／MuteとSafety Limiterを通して出力します。
- FX1のMONは選択TimbreのFX1直後をMasterへ一時的に直結します。Sessionには保存しません。

## 保存と読込

- 新規Timbreは`timbre-v21`、新規Sessionは`session-v23`で保存します。Pattern長、OSCのSingle／Multi・LFSRの設定、2系の行き先・Balance・FEnv Depth・AEnv2、FILTER2のStage2・FEnv Target・GainはTimbre、Frame長と時間方式はSessionに保存します。旧形式はSingle、Balance 0、FEnv Depth 0、既定のAEnv2、Stage2 Offで読み、`timbre-v20`以前のLPF／HPFのQ（dB値）は線形値へ換算するので、音は変わりません。0.5.0-rc.1以前のLabは新形式を読み込めません。
- 対応する旧形式は、位相、BURST、Pattern、Pan、Pattern長、Frame長など不足項目を規定値または旧設定から補って読込みます。不正・未知・重複した構造はライブ音声グラフへ適用する前に拒否します。
- Sessionは8枠、Pattern、SONG欄の設定、共通空間を含みます。個別TimbreのLoadは共通空間と時間方式を変更しません。
- DemoとSession Loadは再生・録音を停止して状態を置換しますが、自動発音しません。

## 操作と表示

- 数値範囲、既定値、線形／対数、Coarse／Fine方式は`src/config/parameterRanges.ts`を正本とします。
- 固定viewport内でTIMBRES、信号図、エディットを意味のある領域ごとにスクロールします。
- エディットのカードは1列に最大3枚まで縦積みできます。OFFのカードはグレー表示ですが、OFF中も編集できます。
- `FILES`はSession名とSave／Loadのダイアログを開きます。×、Esc、外側のタップで閉じ、下の画面構成は変えません。操作結果とエラーはヘッダーのステータス行に1行で示し、タップでFILESの全文表示を開きます。
- Timbreの`Clear`／`Init`はMuteから離れた位置にあり、音色の入った枠では確認します。
- 表示の下限はiPad Air縦向き（820×1180）です。上部の`Map`で信号図を、`TIMBRES`でTIMBRES領域を開閉します。幅600 px以下では`Seconds`を`Sec`と略し、ヘッダーのBPMを隠します。
- iPadでは編集可能な入力以外の長押し文字選択を抑止します。タッチによるAudioContext再開はpointerupでも再試行し、解放済みGateを遅延発音させません。
