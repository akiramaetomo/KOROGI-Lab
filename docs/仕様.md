# KOROGI-Lab — 公開仕様

## 音源と発音

- 8つのTimbreは独立したモノフォニック音源です。各Timbreは2 OSC、PEnv、MOD、FILTER1／2、AEnv、BURST、FX1を持ちます。
- OSC1／2はsine、sawtooth、triangle、square、white noiseを選択できます。周期OSCはTimbre共通のSYNC／FREEを持ちます。
- Manualは押下中Gate、AutoはTonと反復周期、USER 1～8は記録したGate／Pitch列を使用します。Play Allは各枠の選択中再生元を共通時刻から開始します。
- AEnvはGateまたはOne-shotです。BURSTはOne-shotを1発として1〜8発の群を構成し、外側のManual／Auto／Userをフレーズ窓として扱います。

## Song

- Gate記録のあるUSERだけを番号順に循環再生します。Secondsは最長Gate選択区間を基準とし、Barsは各Gate／Pitch選択区間を指定BPM・小節数へ個別に比例配置します。Song Speedは両方式に作用します。
- 記録済みの秒位置は変更しません。Bars録音のBPMはRecord欄でも編集でき、SongのBPMと共通です。
- Gateクオンタイズは Bars 方式でのみ有効です。Gate再生範囲を原点とするFit to Barsの4/4格子へ、独立した編集範囲内のGateを量子化します。1/4・1/8・1/16・1/32、ONのみ（長さ維持）・ON/OFF、Gap 1～20 ms、直近1操作のUndo／Redoを持ちます。Gapは記録秒であり、Songの比例配置とSpeedで再生時の長さが変わります。

## SEQUENCEの入力

- Separate未選択ではスライダがGate＋Pitchを兼ね、選択中は独立GateボタンとPitch専用スライダになります。Record対象レーンを優先し、Playでは手動保持中のレーンだけをコントローラへ切り替え、解放時に進行中の記録・Auto・Songの現在位置へ戻します。Separateは一時状態で保存しません。

## Mixと空間処理

- FX1前は固定−18 dBです。歪量はFX1 Drive、完成したTimbreの音量はFX1後Levelで調整します。
- FX1後にL/R Panと等電力Near／Far送信を適用します。Near／FarはそれぞれFX2、FX3、Bus Gainを持ちます。
- Output BalanceでNear／Farを等電力合成し、Master Gain／MuteとSafety Limiterを通して出力します。
- FX1のMONは選択TimbreのFX1直後をMasterへ一時的に直結します。Sessionには保存しません。

## 保存と読込

- 新規Timbreは`timbre-v17`、新規Sessionは`session-v20`で保存します。カードを3段に積んだ列を含むファイルは、0.2.0-rc.1では読込を拒否されます。
- 対応する旧形式は、位相、BURST、User Pattern、Panなど不足項目を規定値で補って読込みます。不正・未知・重複した構造はライブ音声グラフへ適用する前に拒否します。
- Sessionは8枠、User Pattern、共通空間を含みます。個別TimbreのLoadは共通空間を変更しません。
- DemoとSession Loadは再生・録音を停止して状態を置換しますが、自動発音しません。

## 操作と表示

- 数値範囲、既定値、線形／対数、Coarse／Fine方式は`src/config/parameterRanges.ts`を正本とします。
- 固定viewport内でTIMBRES、信号図、エディットを意味のある領域ごとにスクロールします。
- エディットのカードは1列に最大3枚まで縦積みできます。ドラッグ中は移動先を枠と挿入辺の帯で示します。OFFのカードはグレー表示ですが、OFF中も編集できます。
- 表示の下限はiPad Air縦向き（820×1180）です。上部の`Map`で信号図を、`TIMBRES`でTIMBRES領域を開閉し、再押下で直前の大きさへ戻します。畳んだTIMBRESの分割バーはタップでも戻ります。幅600 px以下では`TIMBRES`ボタンを隠し、タップで戻します。
- iPadでは編集可能な入力以外の長押し文字選択を抑止します。タッチによるAudioContext再開はpointerupでも再試行し、解放済みGateを遅延発音させません。
