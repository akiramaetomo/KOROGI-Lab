# KOROGI-Lab — 公開後の開発計画

## 現行0.1.0の保守

- 公開サイトのHTML、現在のhashed asset、版表記を独立に確認し、workflow成功だけで公開完了としません。
- 音声処理や数値範囲を変更した場合は、単体・ブラウザ数値検査と実機聴感を別々に扱います。
- 保存形式を変更する場合は、新規保存、旧形式移行、不正入力拒否を同じ変更境界で監査します。
