# KOROGI-Lab — 公開版の現在状態

更新日: 2026-10-20

## 現在地

KOROGI-Lab 0.5.0-rc.1は公開候補です。OSC1／2にSingle／Multi（同じ波形を1～16基加算）を加え、OSC2系の行き先にAEnv IN／AEnv OUTを加えて、2系統の音色を1つのTimbre内で重ねられるようにしました。AEnv OUTでは独立したAEnv2を使い、1系／2系のBalanceとFEnvのFilter2への掛かり具合を調整できます。TIMBRE図は1系・制御・2系の対称な3段になりました。保存形式は`timbre-v20`／`session-v23`へ上げ、旧形式は音を変えずに読込みます。新形式は0.4.0-rc.1以前では読込めません。

## 0.5.0-rc.1の検証

- 開発正本で単体170件、Chrome 389件、型検査、production build、Pages用ビルド、成果物スモーク試験が成功しました。OSC2の音声経路はOfflineAudioContextの数値試験（経路ごとの有無、Balanceの端点、AEnv2の独立性、FEnv Depth、BURSTでのRelease）で確認しています。
- 作者がPC／iPadで、OSC Multiの動作と、2系統の合成による606系の音作り、3段の信号図を受け入れています。組合せごとの妥当性は使用しながら確認中です。
- 既知の処理負荷の課題: SYNCで無音から発音するたびに、古い発振器の組を約50 ms計算し続けます。Multiではこの量が成分数倍になります。対処は未決です。

## 0.4.0-rc.1の概要

KOROGI-Lab 0.4.0-rc.1は公開候補でした。アプリ全体の時間方式`Seconds | Bars`（既定はBars）を導入し、BarsではTimbre×Patternごとの長さ（1/16～32小節）とBPMへ選択区間を伸縮して、共通の小節格子で再生・録音します。Play AllをLoop、Song再生をChainと改め、ChainはSession共通のFrame長の区間でPattern 1→8を順送りします。SONG欄にTimbre×Patternの格子を加え、Chainで鳴らすPatternの選択、SEQUENCEへの移動、鳴っているPatternの表示を行います。録音中のPitch設定・Separateの変更、FILESダイアログとステータス行、Clear／Initの確認、Song中のBPM変更によるハングの修正も含みます。保存形式は`timbre-v18`／`session-v21`でした。
