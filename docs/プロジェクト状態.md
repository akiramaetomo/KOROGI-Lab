# KOROGI-Lab — 公開版の現在状態

更新日: 2026-10-07

## 現在地

KOROGI-Lab 0.3.0-rc.1は公開候補です。新規保存形式は`timbre-v17`／`session-v20`のままです。8つの独立したTimbreと共有Near／Far空間に加え、USER 1～8のGate／Pitch記録、SongのSeconds／Bars再生、Song Speed、USERパターンのコピーを実装しています。0.3.0-rc.1では、Bars方式のGateクオンタイズ、SEQUENCEのSeparate、カードの3段積み、iPad Air縦向きの下限表示、`TIMBRES`／`Map`の開閉ボタンを加えました。3段の列を含むファイルは0.2.0-rc.1では読込めません。実機操作・聴感の受入前のため、安定版とはしません。

- 公開専用リポジトリで`npm ci`、単体110件、型検査、Pages用ビルド、成果物スモーク試験が成功しました。
